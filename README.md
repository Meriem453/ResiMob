# 🏢 Resimob

This mobile application **enhances communication** between **students** and **residence administrators**. It provides essential services like **lost object declarations, announcements, restaurant schedules, and maintenance requests**.

## ✨ Features  

### 🎓 Student Interface  
- 📢 **View Announcements** – Stay updated with residence news.  
- 🔍 **Lost & Found** – Declare lost objects and check found items.  
- 🍽️ **Timings** – Restaurant and bathrooms timings.  
- 🏋️ **Weekly Programs** – For sport halls and reataurant meals.  
- 🛠️ **Request Maintenance** – Report issues to admin (plumbing, electricity, etc.).  

### 🏛️ Admin Interface  
- 📢 **Post Announcements** – Share important updates.  
- 📦 **Manage User's Accounts** – Create and manage students accounts.  
- 🛠️ **Handle Maintenance Requests** – Assign and track reported issues.  
- 🏋️ **Update Schedules** – Modify restaurant, bathroom, and sports timing.  

---

## 🔑 Key Technologies  
- 🤖 **Kotlin** – Native Android development.  
- 🎨 **XML** – UI design.  
- ☁️ **Firebase** – Real-time database, authentication, and cloud storage.
